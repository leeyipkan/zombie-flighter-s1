# 安全屋儲物櫃 — 改造計劃

> 版本 1.0 · 2026-11-14
> 目標：`zombie-flighter-s1`（屍潮餘燼 · DEAD BLOCK）
> 狀態：已照本計劃實作（`index.html`），QA 109 條全過

---

## 1. 問題

- 背包固定 **12 格**，探索一趟通常會同時帶：武器、護甲、食物、2–4 種零件、圖紙任務物。
- 材料捨不得丟、食物不能存，結果是「回程撿不下 → 來回跑」或「把材料用掉做沒那麼急的東西」。
- 這是個好取捨，但不該讓玩家在**安全屋裡**還被背包卡住。

## 2. 目標與非目標

**目標**
- 在安全屋提供一個**可擴建**的儲物空間，讓玩家把「備用材料／備用裝備」留在基地。
- 保留背包 12 格的取捨：儲物櫃解決的是「回程存放」，不是「出門多帶」。
- 不改戰鬥、探索、屍潮節奏；不新增即時壓力。

**非目標（本次不做）**
- 不增加背包格數、不做重量制。
- 不讓工作臺直接從儲物櫃扣材料（避免「材料在櫃子裡也能做」的隱形規則）。
- 不做多個儲物點、不做櫃內物品被屍潮破壞。

## 3. 設計

### 3.1 位置與互動
- 安全屋（左上）內新增一個**兩門鐵櫃**，位置 `(9, 4)`，就在工作臺對面。
- 站在旁邊（含斜角）按 `E` 開啟；與工作臺互不干擾。
- 安全屋在啟動訊號前是安全區（見 §4），所以在這裡整理物資是安全的。

### 3.2 容量與擴建
| 等級 | 格數 | 升級材料 |
|---|---|---|
| Lv.1 | 24 | —（初始） |
| Lv.2 | 36 | 木板 ×4、廢鐵 ×3、膠帶 ×2 |
| Lv.3 | 48 | 廢鐵 ×6、木板 ×4、膠帶 ×3 |

- 升級材料可以來自**背包或儲物櫃**（取用時先扣背包，再扣櫃子）。
- 升級按鈕直接顯示「目前 / 需要」，材料不足時變灰。

### 3.3 轉移規則
- **點擊**：移動 1 個（堆疊物一次一個）。
- **Shift + 點擊**：整組移動（裝備一次就是 1 件）。
- **存入全部材料**：把背包裡所有 `type = mat` 的堆疊搬進櫃子，食物／裝備不動。
- **取出全部**：櫃子裡的東西依序搬回背包，背包滿就停。
- 裝備（武器／護甲）保留各自的耐久，不會回滿。
- **訊號發射器不能存**（跟不能丟棄同一個理由：它是通關物）。

### 3.4 邊界與錯誤處理
| 情況 | 行為 |
|---|---|
| 櫃子滿了還要存 | 拒絕、提示「儲物櫃滿了」、物品留在背包 |
| 背包滿了還要取（需要新格） | 拒絕、物品留在櫃子；可堆疊的仍可合併 |
| 存入發射器 | 拒絕並提示 |
| 舊存檔沒有 `stash` 欄位 | 視為空櫃、Lv.1，不影響讀檔 |
| 死亡／通關 | 存檔清除，櫃子內容一并消失（新局重新開始） |

### 3.5 存檔格式
```json
{
  "v": 1,
  "stash": [{ "id": "scrap", "n": 12 }, { "id": "machete", "n": 1, "dur": 31 }],
  "stashLv": 2
}
```
- 沿用 v1，舊存檔缺欄位時走預設值，不需要 migration。
- 讀檔時過濾未知物品、夾住耐久與等級。

### 3.6 介面
- 標題「儲物櫃」，兩欄：左「背包 6/12」、右「儲物櫃 · Lv.2 3/36」。
- 每格顯示圖示、堆疊數、裝備耐久條；滑鼠移上去有名稱與耐久。
- 底部：`存入全部材料`、`取出全部`、`擴建到 Lv.N（材料 目前/需要）`、提示文字。
- 與現有 UI 一致：無動畫、無補間，點擊立即結算。

## 4. 與「安全屋安全區」的關係
- 探索階段：喪屍進不了安全屋（`zombieBlocked`），儲物櫃是安全的。
- 啟動訊號後：安全屋六個缺口被打開，屍潮灌入——**這時櫃子不再安全**，玩家要決定先守門口還是先補給。

1. 常數：`STASH_CAPS = [24,36,48]`、`STASH_UPGRADES`。
2. 狀態：`S.stash = []`、`S.stashLv = 1`。
3. 地圖：安全屋 `(9,4)` 新增 `stash` prop、標籤與鐵櫃繪製。
4. 互動：`nearStash()`、`interact()` 優先開啟儲物櫃、底部提示。
5. 邏輯：`addToStash`、`bagToStash`、`stashToBag`、`depositAllMaterials`、`withdrawAll`、`upgradeStash`、`countAny/consumeAny`。
6. UI：`renderStash()` 兩欄面板、點擊／Shift 點擊、擴建按鈕。
7. 存檔：`saveGame` / `continueGame` 加入 `stash`、`stashLv`。
8. 測試：QA 新增 24 條（容量、轉移、滿包/滿櫃、耐久、擴建、存讀、互動）。
9. 部署：commit → `zombie-flighter-s1` → GitHub Pages 自動重建。
